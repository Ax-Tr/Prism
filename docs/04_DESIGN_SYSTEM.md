# 04 — Design System Specification: Nexora Prism

## 1. Color Palette Tokens

| Token Name | Hex Code | Purpose |
|------------|----------|---------|
| Background Dark | `#050505` | Primary dark theme backdrop |
| Background Light | `#f2f0eb` | Primary light theme backdrop |
| Surface Dark | `#0b0f19` | Glassmorphic panel base |
| Cyan Accent | `#38bdf8` | Primary neon highlight & CTAs |
| Purple Accent | `#c084fc` | Meridian roadmap & Sanctum tokens |
| Emerald Accent | `#10b981` | Success states & OKR track indicators |
| Amber Accent | `#f59e0b` | Warnings, risk flags & Leaderboard |
| Rose Accent | `#f43f5e` | Critical priority badges & Checkpoint urgency |

## 2. Typography Tokens
- **App UI Font**: `Outfit` (sans-serif)
- **Landing Body Font**: `Inter` (sans-serif)
- **Serif Accent**: `Cormorant Garamond` (serif)
- **Monospace Token Font**: `Space Mono` (monospace)

## 3. Spacing & Border Radius System
- **Border Radius**: `rounded-xl` (12px), `rounded-2xl` (16px), `rounded-3xl` (24px), `rounded-full` (9999px)
- **Backdrop Blur**: `backdrop-blur-md` (12px), `backdrop-blur-xl` (20px), `backdrop-blur-2xl` (40px)
