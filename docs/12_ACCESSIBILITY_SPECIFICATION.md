# 12 — Accessibility Specification: Nexora Prism

## 1. WCAG 2.1 AA Compliance Strategy
- **Keyboard Navigation**: All dock tabs, buttons, forms, and modal dialogs are fully navigable via `Tab` / `Enter` / `Space`.
- **Focus Indicators**: Visible focus outlines on all interactive elements (`focus:outline-none focus:border-sky-500`).
- **Color Contrast**: Compliant contrast ratios across both dark (`#050505`) and light (`#f2f0eb`) theme modes.
- **ARIA Attributes**: `aria-label` attributes on icon buttons (theme toggle, notifications, Luminary trigger).
